# Applied AI Module Book — Source Note

## Source

`APPLIED AI MODULE BOOK V1.pdf`

## Type

Official Applied AI module book, 2026–2027, version 1.0 / 01-09-2026.

## Authority

**Authoritative** for the research-paper assignment process and its place in the wider module.

## Purpose

Defines module learning outcomes, assessment architecture, period-1 Go/no-go, portfolio evidence, curriculum timing and Appendix 3 research-paper assignment.

## Research-Paper Requirements

- Pair paper during the first four weeks.
- Topic related to Applied AI.
- Initial proposal with topic, provisional title, one main question and three subquestions.
- Lecturer discussion and approval of title/questions before writing.
- Relevant/reliable sources, coherent argument, evidence-based answers and distinction between source information, own analysis and conclusions.
- Peer review in week 3; evidence of received and provided feedback in the portfolio.
- Final submission Friday of week 4 according to Teams instructions.
- Paper assessed Sufficient/Insufficient.
- A Sufficient paper is mandatory for period-1 Go/no-go.

## Wider Module Context

Six module learning outcomes and HBO-i competences exist, but the module book primarily maps them to project, learning path and portfolio evidence. No explicit direct mapping of the period-1 research-paper rubric to a specific learning outcome is stated.
