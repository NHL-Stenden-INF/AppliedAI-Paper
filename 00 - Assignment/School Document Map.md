For paper-specific conflicts, use specificity and current version first. The practical precedence used here is:

1. official research-paper assessment form for direct paper form/content criteria;
2. official module-book research-paper assignment for process, timing and Go/no-go role;
3. wider official module requirements for contextual learning outcomes/assessment architecture;
4. formal written assignment-specific lecturer instruction, if later provided;
5. formal methodology/APA/template guidance, if later provided;
6. formal feedback;
7. lecture material/examples/informal notes.
