# Conclusions Matrix

| Research question | Evidence threshold before conclusion | Current evidence | Analysis route | Conclusion status | Confidence | Missing before conclusion |
| --- | --- | --- | --- | --- | --- | --- |
| SQ1 | Multiple relevant sources support a defensible current technique taxonomy across final scope | None | Taxonomic/thematic synthesis | Not Yet Available | None | Academic source set, final scope and taxonomy |
| SQ2 | Sufficient empirical results with metric/dataset/test context, including evidence beyond only in-domain benchmarks | None | Contextual comparative synthesis | Insufficient Evidence | None | Performance + generalisation evidence and operational real-world definition |
| SQ3 | Direct evidence for key degradation/generalisation/evasion factors with context | None | Thematic/effect synthesis | Insufficient Evidence | None | Robustness/generalisation/evasion studies |
| MRQ | SQ1–SQ3 answered with traceable evidence, source quality assessed, major contradictions addressed | None | Integrative synthesis | Not Yet Available | None | Completed subquestion syntheses |

## Rule

Do not write a final conclusion merely because a question has some evidence. The evidence must be sufficiently direct, contextualised and complete for the scope. Conflicting results reduce or qualify confidence rather than being discarded.
