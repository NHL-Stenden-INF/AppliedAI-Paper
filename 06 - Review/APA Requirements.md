# APA Requirements

## Official Requirement

The research-paper assessment form explicitly requires APA to be well applied and separately assesses the literature list as APA-compliant.

## APA Version

**Official APA edition: To Verify.**

No uploaded school document explicitly names the edition.

**Working default for later drafting: APA 7**, only because the setup instructions specify APA 7 as the fallback when school documentation is silent. This is not presented as a school-confirmed rule.

## Citation Rules — Planning Checklist

Until school-specific deviations are found:

- cite every non-common-knowledge claim derived from a source;
- keep in-text citations consistent with the reference list;
- include page/paragraph locators for direct quotations as required by APA;
- distinguish source claims from the authors' own synthesis;
- avoid orphan references that are never cited and citations without matching references.

## Reference-List Rules

- one consistent APA-formatted reference list;
- complete bibliographic metadata where available;
- DOI/URL treatment according to the applicable APA edition;
- alphabetical ordering according to APA rules;
- exact author/year/title/source matching with in-text citations.

## Figures

The school assessment form requires figures/tables to support the text and be referenced correctly. Later drafting should apply APA figure numbering, title/notes/source attribution according to the confirmed APA edition.

## Tables

Later drafting should apply APA table numbering, title/notes/source attribution according to the confirmed APA edition and must refer to each table in the text.

## Appendices

No school-specific paper appendix formatting rule is present in the uploaded documents. Follow the confirmed APA edition unless Teams instructions specify otherwise.

## Direct Quotations

No school-specific quotation rule is present. Follow the confirmed APA edition and use direct quotations sparingly where paraphrase is more appropriate.
