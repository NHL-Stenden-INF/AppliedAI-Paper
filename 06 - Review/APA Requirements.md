# APA Requirements

## School-Confirmed Requirement

The research-paper assessment form explicitly requires APA to be well applied and separately assesses the literature list as APA compliant.

## APA Version

**Official APA edition: To Verify.**

No available school document names a specific APA edition. The Applied AI module book does not provide a paper-specific APA guide in the Project files.

## Project Working Default

**APA 7** is used only as a project fallback because the project setup instructions specify APA 7 when school documentation is silent. This is **not** a school-confirmed rule.

## Working APA Checklist for Later Drafting

Until school-specific guidance is supplied:

- cite sourced non-common-knowledge claims;
- maintain one-to-one consistency between in-text citations and reference-list entries;
- distinguish sourced findings from authors' synthesis;
- use locators for direct quotations as required by the applicable APA edition;
- keep bibliographic metadata complete where available;
- use DOI/URL rules from the confirmed/default edition;
- number/title/credit figures and tables consistently and refer to them in the text;
- format appendices under the confirmed/default edition unless school instructions override it.
